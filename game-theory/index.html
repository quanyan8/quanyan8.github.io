Lectures on Static and Dynamic Game Theory

Foundations for Multi-Agent Systems and Control

Tamer Başar (University of Illinois Urbana-Champaign) and Quanyan Zhu (New York University)

Game theory is the mathematical study of strategic interactions among rational decision-makers. Where classical decision theory models an agent as an isolated optimizer in a fixed environment, game theory begins from interdependence: each player forms expectations about others who are reasoning about them in turn. These lectures develop that theory from matrix games to mean-field and learning games, with the multi-agent systems, control, and security problems that motivate it.

Equilibria

In a zero-sum game the mixed equilibrium is the saddle point, and the equilibrium payoff is the value of the game: what each player can guarantee with a security strategy, whatever the other does (§2.1.2, §2.2).
